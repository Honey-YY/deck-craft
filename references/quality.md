# 验收清单

交付前逐条过。前八条是硬的，过不了不许交。

---

## 硬指标

### 1. 每页标题都是判断句

把 14 个标题连起来读，像不像一段有逻辑的话？

```
怎么做出好演示稿 / 这份稿子讲五件事 / 先想清楚给谁看 /
没想清楚受众的三个信号 / 把分类名改成观点 / 三种页面骨架覆盖九成场景 /
一页的字数上限 / 观众记住的是形状 / 一份稿子的生成顺序 / ...
```

像 → 过。出现「市场分析」「产品规划」→ 回去改。

### 2. 没有编造的数字

逐个数字问：这个数字从哪来？

- 用户给的 → 过
- 我查到的 → 过（并注明出处）
- 我编的 → **必改**。换成定性判断，或在图上明确标「示意」

### 3. 一页只有一个观点

随机抽三页，问：这页在讲什么？只能有一个答案。

出现「同时」「另一方面」「此外还有」→ 拆页。

### 4. 没有占位符残留

`check.mjs` 会查 `{{...}}`、`TODO`、`Lorem`、`待填`。

### 5. 主题唯一

整份稿子 `data-theme` 只出现一次。

### 6. 页码连续

01 到 N，最后一页可以写 `N / N`。不能跳号，不能重复。

### 7. 只有第一页带 `on`

多个 `on` 会导致打开时同时显示多页。

### 8. 单文件能独立打开

`dist/deck.html` 拷到别的目录，双击，能放。

验证方法：把 dist 里的文件单独复制到一个空文件夹，打开。图挂了就说明有外链资源。

## 视觉指标

### 9. 文字不溢出

`check.mjs` 会按标题字数预警，但它只是估算。真正的验证是打开看一眼：

- 标题有没有被截断
- 卡片里的文字有没有顶出边框
- 表格最后一行有没有被页脚压住

**一定要真的打开一次。**没打开就交付，等于没验收。

### 10. 对比度够

深色主题下，`--muted` 的文字在投影仪上常常看不清。如果这份稿子要在会议室放，正文别用 `.muted`，用 `--fg-2`。

快速判断：把屏幕亮度调到 40%，还能读吗？

### 11. 节奏不塌

连续三页同版式会塌。`check` 会提醒。

抽掉任何一页，稿子还成立吗？如果某页抽掉毫无影响，那页就是凑数的，删掉。

### 12. 图文平衡

全是文字 → 观众疲劳。
全是图 → 没有论点。

经验：每 4–5 页至少有一个 `stat`、`chart` 或 `image`。

## 逻辑指标

### 13. 开场 30 秒说清了什么

第一页 + 第二页，能不能让一个没背景的人知道：这份稿子要解决什么问题？

不能 → 封面副标题和大纲需要重写。

### 14. 结尾有明确动作

`end` 页写的是「谢谢观看」→ 改。

应该写：要谁、在什么时候、做什么决定。

### 15. 有没有废话页

- 「背景介绍」——大部分场合可以删
- 「团队介绍」——除非是路演或投标
- 「目录」——超过 8 页才需要
- 「Q&A」——一页写 Q&A 是浪费，直接留白或用 `end`

删掉后页数变少不是问题，讲得更清楚才是。

## 交付话术

交付时说三件事，不要多：

```
文件：dist/deck.html（14 页，37 KB，单文件）

放映：双击 → ← → 翻页 → F 全屏
改字：直接用编辑器打开，搜关键词定位
换肤：改第 2 行的 data-theme
PDF：浏览器 Ctrl/Cmd+P → 另存为 PDF → 边距「无」→ 勾「背景图形」
```

如果做了假设（默认受众、默认页数），在这里一并说明，一句话：

> 你没说页数，我按 12 页做的；如果是要在 10 分钟里讲完，建议砍到 8 页。

## 一份合格稿子的样子

```
1  cover     判断句标题 + 一句副标题
2  agenda    3–5 项，每项一行
3  section   01
4  bullets   一个结论 + 三条支撑
5  columns   前后对照
6  cards     三个模块
7  stat      三个数字
8  chart     一组条形 + 一句结论
9  section   02
10 timeline  四到五个阶段
11 quote     一句原则
12 table     参数对照
13 process   四步
14 end       明确的行动号召
```

这个结构能覆盖 80% 的内部汇报场景。照抄不丢人。
